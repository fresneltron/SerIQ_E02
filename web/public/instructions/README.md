# Утверждённые видеоинструкции

Плеер приложения ожидает четыре файла с такими именами:

- `E01.mp4` — поднять лёгкий предмет
- `E02.mp4` — разогнуть локоть
- `E03.mp4` — поднять кисть
- `E04.mp4` — раскрыть ладонь

Клип `video2.mp4` используется как демонстрация E02. В интерфейсе можно переключаться между видео и 3D‑манекеном. Для Vercel ролик находится в `public/instructions/video2.mp4`; если файл также загружен в Supabase Storage в публичную корзину `instruction-videos` под именем `video2.mp4`, приложение использует облачную копию.

Остальные короткие клипы можно добавить сюда с именами `E01.mp4`, `E03.mp4` и `E04.mp4` после проверки с реабилитологом. Подойдут спокойная съёмка сбоку, полностью видимая рука, один медленный повтор, нейтральный фон, без музыки и текста внутри кадра. Локализованные подписи приложения показываются под видео.

Не копируйте сюда клипы из папок Train/Test или `demo_videos`: это записи участников набора данных для оценки модели, а не утверждённые инструкции.
